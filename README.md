# Bujji Non Veg Pickles Website

Production-ready Next.js website for Bujji Non Veg Pickles, Tenali.

## Run
```bash
npm install
npm run dev
npm run build
```

## Deploy
Import this GitHub repository into Vercel. Optionally set NEXT_PUBLIC_SITE_URL to the final domain.

## Client confirmations
- FSSAI number
- exact product availability, sizes and prices
- shipping charges/timelines
- shelf life and storage guidance
- payment methods
- exact opening hours
- founding year/story
- packaging details
